# ⚡ Neo-Match: God-Tier Tic-Tac-Toe

A high-performance, futuristic Tic-Tac-Toe engine featuring a **Quantum Minimax AI**, adaptive difficulty, and a sleek neon UI. Built for the web with pure JavaScript.



## 🚀 Live Demo
**Play it here:** [https://growingsoul-sar.github.io/tictactoe/](https://growingsoul-sar.github.io/tictactoe/)

## ✨ Features
* **🤖 Quantum AI:** Powered by the Minimax algorithm. It's nearly impossible to beat.
* **🏆 Tournament Mode:** Best of 3 match system with a "God Badge" reward.
* **🌓 Dual Themes:** Switch between "Cyber-Dark" and "Retro-Light" modes.
* **🔊 Audio Synth:** Real-time synthesized sound effects (no external files needed).
* **📱 Responsive:** Optimized for both PiBooks and Mobile devices.

## 🛠️ Tech Stack
* **HTML5 & CSS3** (Custom Animations & 100dvh layouts)
* **JavaScript** (Minimax AI, Web Audio API)
* **GitHub Pages** (Hosting)

## 🕹️ How to Play
1. Enter your name in the Lobby.
2. Select your opponent (Quantum AI or Local Human).
3. Be the first to win 2 rounds to earn your Badge!
